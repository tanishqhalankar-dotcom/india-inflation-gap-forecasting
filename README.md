
# Forecasting India's Inflation Gap

A time-series forecasting project examining India's inflation gap relative to the 4% inflation target.

## Methods

* ADF and KPSS stationarity tests
* Seasonality testing
* ACF, PACF and EACF analysis
* ARMA model estimation
* Residual diagnostics using the Ljung-Box test
* 12-month out-of-sample forecast evaluation
* Model comparison using AIC, MAE and RMSE
* Three-month forward forecasting

## Models Evaluated

* ARMA(1,3)
* ARMA(2,3)
* ARMA(3,2)

## Output

The project evaluates model forecasting performance against a 12-month holdout sample and generates forward forecasts for India's inflation rate.
